# 无需卡号的金融数据流程

2026-11-25：按用户选择停用 Tushare。当前 A 股研究默认使用已有 BaoStock 适配器及其经过文件哈希校验的本地缓存。AKShare 适配器仍可单独用于价格获取/核对；不会自动替换缺失的停牌、历史 ST 或涨跌停字段。

## 一条命令运行两个项目

在 `quant-research-lab` 目录：

```bash
bash scripts/run_open_data.sh
```

三个项目应并列放在同一个目录，分别完成各自 `.venv` 的依赖安装。入口不增加 Python 依赖，也不读取卡号；默认只读取 BaoStock 缓存。每次生成独立输出目录，禁止覆盖之前的实验。

默认研究样本为2020-01-02至2024-12-31，6只股票：000001.SZ、300750.SZ、600000.SH、600518.SH、600519.SH、688981.SH。它是检查研究设施的选定样本，不是全市场或无幸存者偏差的股票池。新上市证券保留实际起始日期，停牌行保留，不为满足统计门槛剔除短路径。

自定义范围或股票、允许从 BaoStock 获取缺失数据：

```bash
bash scripts/run_open_data.sh --online \
  --start 2020-01-02 --end 2024-12-31 \
  --codes 600000.SH 000001.SZ --output output/baostock_custom
```

`--online` 允许补齐缺口，不代表强制刷新已有缓存。默认缓存模式在运行前检查请求区间、日历范围、证券资料及缓存文件完整性；缺失就停止，不暗中联网或使用模拟数据。在线网络故障同样不替换为人工数据。

若只导出而不运行两项研究，加 `--export-only`。默认 alpha 计划要求每条路径至少630行；不足时明确停止，请事先登记合适的研究配置，不能直接删掉退市/短历史证券来使样本通过。高级配置可在导出后分别通过两个项目各自的 `--config` 命令运行。

## 已完成的真实缓存验收

输出：`output/baostock_free_20261125/`。

- 数据：6只股票，7,144条日线，34条停牌记录，5条涨跌停未知记录。未知涨跌停且未豁免时拒绝成交。
- 研究来源：校验通过的本地真实 BaoStock 缓存，不是今天新下载的数据。
- quant：57个滚动测试段、171次候选评估，生成 `quant/report.html`。
- alpha：378次尝试、42批冻结，完成审计和文件哈希核验，生成 `alpha/report.html`。
- alpha 的精确时间簇检验没有支持 random 或 memory 相对 ordered 的增量优势；两项比较均未通过研究门槛。跑通软件不代表策略有效。
- 当天独立在线小样本探测在25秒超时；不承诺当前网络可用。在线超时不会影响已有完整缓存的离线复现。

数据包沿用 `research_bundle_v1`。alpha 和 quant 导入器分别校验其文件哈希；导出报告保留原始来源/缓存版本。两个项目的研究问题和实际使用窗口不同，不能把两份收益当作策略之间的公平比赛。

## Yahoo Finance 的适用范围

本次选择 BaoStock，保持 A 股交易日、停牌与历史 ST 信息链条。没有将 Yahoo 的缺失字段填成“可自由成交”。Yahoo/yfinance 可用于另一个全球资产日线研究适配器，但当前引擎以 Asia/Shanghai 的决策和成交时点为基础，全球市场需要先加入交易所时区、夏令时、日历和资产交易规则，再运行完整回放。当前未宣称已经完成该适配器。

依据 [yfinance 项目说明](https://github.com/ranaroussi/yfinance)，它是调用 Yahoo 公共接口的开源工具，不是 Yahoo 官方客户端；调整价格与使用条款应按具体数据用途核对。
